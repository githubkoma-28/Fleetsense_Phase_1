# Fleetsense_Phase_1
NYC Taxi Trip Analysis Dashboard built using Streamlit + DuckDB, analyzing 12 months of NYC TLC Yellow Taxi Trip Data with Taxi Zone Lookup Dataset.
Project: NYC Taxi Trip Performance Analysis
Source: NYC TLC Yellow Taxi Trip Data (12 Months) with Taxi zone lookup dataset.

**What It Does**

KPIs: Total Trips, Total Revenue, Average Fare, Average Trip Distance, Total Tips.
Revenue Analysis: Analyze total revenue, fare amount, tolls, tips, and additional charges.
Trip Analysis: Evaluate trip distance, passenger count, and trip duration.
Payment Analysis: Identify the most popular payment methods.
Pickup & Drop-off Analysis: Identify the busiest pickup and drop-off locations.
Monthly Trends: Analyze monthly trip volume and revenue trends.
Performance Analysis: Compare trip performance across vendors and locations.
Interactive Dashboard: Explore key insights using Power BI filters and visualizations.

How to Run Locally

git clone YOUR_GITHUB_REPOSITORY_URL
cd NYC-Taxi-Trip-Analysis
pip install -r requirements.txt
Run Python scripts or open the Power BI dashboard to explore the analysis.
